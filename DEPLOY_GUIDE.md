# Cập nhật GitHub Pages – v11

Sau khi kiểm thử cục bộ:
1. Giải nén ZIP.
2. Trong GitHub repository hiện tại, xoá/thay các tệp website cũ nếu cần.
3. Chọn **Add file → Upload files**.
4. Kéo **các tệp bên trong** thư mục v11 lên GitHub. Không kéo thư mục mẹ.
5. Kiểm tra chắc chắn có `index.html`, `style.css`, `app.js`, `config.js`, các tệp dữ liệu Tin 10/Tin 11.
6. Commit changes.
7. Vào **Settings → Pages**, Source: Deploy from a branch, Branch: `main`, Folder: `/(root)`.
8. Chờ GitHub Pages cập nhật, sau đó mở website và thử một bài Tin 10, một bài Tin 11 và kiểm tra Google Sheet.
